Meitou now has its own **launcher**. It installs game releases straight from GitHub, keeps several versions side by side
and starts the one you pick.

- **Mods**: the same list as Kenshi's launcher, writing the same `mods.cfg`, so it works for the original game too.
  Drag mods to change the load order and keep sets of them as **presets**.
- **Versions**: stable releases, or pre-releases if you want them. Downloads are checked and can be cancelled.
- **Updates**: the launcher updates itself.

Linux and macOS builds of the game arrive with 0.15.0. Downloads and notes are on the
[releases page](https://github.com/VlcekM/MeitouClient/releases).
